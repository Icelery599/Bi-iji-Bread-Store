# Bread Making Store

A web-based platform for browsing and purchasing freshly baked bread products.

## Features

- Product browsing and catalog
- User authentication
- Shopping cart functionality
- Booking system
- Responsive design for mobile and desktop
- Checkout process

## Project Structure

```
Bread making store/
├── html/
│   ├── index.html          # Home page
│   ├── about.html          # About page
│   ├── account.html        # User account page
│   ├── bookings.html       # Bookings page
│   ├── checkout.html       # Checkout page
│   ├── css/
│   │   ├── style.css       # Main stylesheet
│   │   └── responsive.css  # Responsive design styles
│   ├── js/
│   │   ├── main.js         # Main JavaScript functionality
│   │   ├── auth.js         # Authentication logic
│   │   └── cart.js         # Shopping cart logic
│   └── images/             # Image assets
└── README.md               # This file
```

## Getting Started

1. Open `index.html` in your web browser
2. Navigate through the site using the menu
3. Browse products and add items to your cart
4. Proceed to checkout when ready
